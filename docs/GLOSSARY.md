# Glossary

## AgentReady

A HumanGoodAI product that prepares documents and data for AI agents.

## Simple Export

The default V1 zip package containing Markdown, README, index, conversion report, data copies, and useful assets when needed.

## Markdown

A simple plain-text format that is readable by humans and practical for agents.

## Partially converted

A file that produced usable output but may have missing structure, incomplete tables, or quality issues.

## Conversion report

A Markdown file explaining what converted successfully, what failed, and why.

## Source document

The original uploaded file.

## Temporary processing

The V1 privacy model where uploaded files are used only to create the export, then deleted.

## Advanced Export

A future mode that may include metadata JSON, JSONL chunks, source maps, database-ready outputs, or embeddings.
