# 00 — Overview

## What is AgentReady?

AgentReady is a HumanGoodAI product that prepares documents and data so AI agents can read them more clearly.

V1 lets a non-technical organization staff member upload common files, convert them into clean Markdown and simple data outputs, preview the result, and download a portable zip package.

## Product promise

> Upload your files. Preview clean Markdown. Download an agent-ready zip.

## What AgentReady is not

AgentReady V1 is not a chatbot, agent host, vector database, website scanner, or permanent document store.

## V1 in one flow

```text
Upload files
-> Convert to Markdown and simple data outputs
-> Preview converted Markdown
-> Download AgentReady Simple Export zip
```

## Primary user

AgentReady V1 is designed first for non-technical organization staff. The interface must not require knowledge of Markdown, RAG, embeddings, vector databases, command line tools, JSONL, or source maps.

## Main output

A portable zip containing:

- `README.md`
- `index.md`
- `conversion-report.md`
- converted Markdown files
- CSV copies of spreadsheet data when needed
- useful assets when needed
