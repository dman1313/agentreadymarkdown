# Product Requirements

## Product

AgentReady by HumanGoodAI.

## Tagline

**Is your data agent ready?**

## Primary user

Non-technical organization staff who need a simple way to prepare documents and data for AI agents.

## Core flow

```text
Upload files -> Convert to Markdown -> Preview Markdown -> Download Simple Export zip
```

## Supported V1 input types

1. PDF
2. DOCX
3. TXT
4. Markdown
5. CSV
6. XLSX

## Limits

1. Up to 25 files per batch.
2. Up to 50 MB per file.
3. Show long-running warning after 60 seconds.
4. Do not auto cancel after warning.

## Non-goals

V1 does not include website scanning, OCR, AI summaries, login, billing, persistent workspaces, embeddings, vector databases, JSONL chunks, or advanced exports.
