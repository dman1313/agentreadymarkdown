# AgentReady V1 SDD Package

This package is a spec-driven design package for **AgentReady V1**, a HumanGoodAI product.

AgentReady prepares documents and data so AI agents can read them more clearly. V1 lets a non-technical user upload files, preview clean Markdown, and download a portable AgentReady zip.

## Start here

1. `docs/SUMMARY.md` — one-screen SDD overview
2. `docs/00_OVERVIEW.md` through `docs/20_BUILD_ROADMAP.md` — implementation-ready spec sections
3. `docs/21_DECISIONS_Q107_Q261.md` — latest product, UX, beta, credits, donation, and future anonymization decisions
4. `docs/adr/` — architecture decisions
5. `docs/prompts/` — build prompts for Codex/VibeCode/OpenClaw
6. `AGENTREADY_V1_SDD_MASTER.md` — full master SDD in one file

## Rule

The spec is the source of truth. If code disagrees with the spec, update one of them deliberately. Do not silently drift.

## V1 promise

> Upload your files, preview the AgentReady Markdown, and download an agent-ready zip.

Latest public product wording: AgentReady helps convert your documents and data into a clean format that is easier for AI agents to read.
