# 19 — Demo Script

## Two-minute V1 demo

1. Open AgentReady.
2. Point to the tagline: “Is your data agent ready?”
3. Explain: “This prepares documents and data for agents by turning them into clean Markdown.”
4. Upload a PDF, DOCX, and CSV sample (use `examples/sample-input/ebooks/minimal.pdf` for a quick PDF win).
5. Show validation and supported file list.
6. Start conversion.
7. Show progress and per-file statuses.
8. Open preview — point out **clean Markdown** vs the original PDF/DOCX layout noise.
9. Toggle rendered Markdown and raw Markdown; mention agents read the raw export with less formatting waste (no exact token promise).
10. Show results with successful and failed files.
11. Explain the export package.
12. Download zip.
13. Open `index.md` and `conversion-report.md`.
14. Close with: “AgentReady does not keep the source documents. You decide where the export goes.”
