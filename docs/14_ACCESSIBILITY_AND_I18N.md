# 14 — Accessibility and I18n

## V1 accessibility rules

- keyboard accessible upload and buttons
- visible focus states
- readable font sizes
- sufficient contrast
- clear status text, not color only
- screen-reader-friendly labels for upload, progress, and results
- no motion dependency

## Language rules

- default copy should be plain English
- avoid developer jargon in V1 UI
- technical terms may appear in docs, not primary interface

## Future i18n

The UI copy should be stored so translations can be added later without rewriting business logic.
