# User Flow Requirements

## Upload page

The upload page shall include:

1. tagline
2. short explanation
3. how it works
4. supported file types
5. file limits
6. privacy message
7. what happens to my files section
8. why Markdown section
9. drag-and-drop upload
10. file picker
11. folder upload where browser support exists

## Selected files

Users shall see selected files before conversion and may remove individual files.

Each file shall show name, type, size, and validation status.

## Progress

Users shall see overall status and basic per-file status.

Users shall be able to cancel.

## Results

Users shall see successful, partially converted, failed, and unsupported files.

Users shall be able to preview Markdown and download the export zip.

## Preview

Users shall preview one converted file at a time with rendered Markdown and raw Markdown options.

Users may copy raw Markdown and download individual Markdown files.

No Markdown editing in V1.
