# 12 — UI/UX Specification

## Screens

1. Upload page
2. Selected files review
3. Conversion progress
4. Results
5. Markdown preview
6. Download ready
7. Thank you/start over

## Upload page must include

- tagline: “Is your data agent ready?”
- simple product explanation
- how it works
- supported file types
- limits
- privacy message
- “What happens to my files?”
- “Why Markdown?”
- drag-and-drop upload area
- file picker
- folder upload when supported

## Preview

- one file at a time
- file list on side
- rendered Markdown/raw Markdown toggle
- copy raw Markdown
- download individual Markdown
- no editing in V1

## Tone

Friendly, simple, calm, trustworthy, and non-technical.
